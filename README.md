## Built for the tiny sizes

Most icons look fine in a preview and then fall apart at watch size. This set
starts at 16x16, then exports upward. The shapes stay simple, the edges stay
hard, and the monochrome files are ready for tinting.

Use this starter to test real layouts before buying the full pack. It includes
the same export structure as the paid set: PNG sizes, monochrome variants,
tints, SVG files, source-grid JSON, a manifest, and a small WFF example.

## Wear OS notes

For Watch Face Format projects, put the PNGs in your project's
`res/drawable*` folders. Android resource names use lowercase letters,
numbers, and underscores, so rename hyphenated files on import:

```text
fish-24.png -> fish_24.png
heart-pulse-24.png -> heart_pulse_24.png
```

Use monochrome or one-bit variants for ambient mode and tintable UI. Use the
base PNGs or tint variants for active/interactive screens.
